# Tasks Module Test Cases - Categorized

## Describe: Task Creation & Configuration
1. Verify that New Task button opens Create New Task drawer.
2. Verify that Create Task shows required field validation when all fields are empty.
3. Verify that Create Task requires Company selection when Company is chosen as association.
4. Verify that Create Task requires Deal selection when Deal is chosen as association.
5. Verify that changing the association radio switches the association field correctly.
6. Verify that Type dropdown shows To-Do, Email, Call, and LinkedIn options.
7. Verify that Priority dropdown shows High, Medium, and Low options.
8. Verify that Task Description character counter updates while typing.
9. Verify that user can create a task successfully from Deal context.
10. Verify that Deal-context Create Task drawer opens without association radio buttons.

## Describe: Task Listing & Management
11. Verify that user can navigate to Tasks module from left navigation.
12. Verify that Tasks list page loads with all expected UI elements.
13. Verify that Tasks list empty state is shown when no tasks exist.
14. Verify that task detail panel opens when a task row is clicked.
15. Verify that task detail panel closes successfully.
16. Verify that Edit Task option opens the update form with pre-filled values.
17. Verify that user can edit task title and save successfully.
18. Verify that Cancel on Edit Task closes drawer without saving.
19. Verify that task can be marked complete via checkbox.
20. Verify that completed task can be toggled back to To-do.
21. Verify that Delete Task action opens confirmation dialog.
22. Verify that cancelling task deletion keeps the task intact.
23. Verify that confirming task deletion removes the task successfully.
24. Verify that sorting works on Task Title column.
25. Verify that sorting works on Due Date column.
26. Verify that Tasks tab opens correctly on Deal detail page.
27. Verify that changing Rows per page updates task listing pagination.

29. Verify that Type filter shows only Email tasks when selected.
30. Verify that Type filter shows only Call tasks when selected.
31. Verify that Type filter shows only LinkedIn tasks when selected.
32. Verify that Priority filter shows only High tasks when selected.
33. Verify that Priority filter shows only Medium tasks when selected.
34. Verify that Priority filter shows only Low tasks when selected.
35. Verify that Status filter shows only To-do tasks when selected.
36. Verify that Status filter shows only Completed tasks when selected.
37. Verify that Due Date range filter works correctly in Tasks module.
